# DAIC 双代币经济模型

## 代币体系

### DAICF (Foundation) - 训练算力代币

| 属性 | 说明 |
|------|------|
| **全称** | Decentralized AI Computing - Foundation |
| **用途** | 奖励提供训练算力的节点 |
| **发行机制** | 1份训练算力 = 1份DAICF |
| **总量** | 无上限（根据实际训练需求） |
| **初始供应** | 1亿枚 |

**奖励机制**：
- 节点完成训练任务 → 获得等量DAICF
- 例如：提供了100算力 → 获得100 DAICF

### DAICO (Operation) - 推理算力代币

| 属性 | 说明 |
|------|------|
| **全称** | Decentralized AI Computing - Operation |
| **用途** | 奖励提供推理算力的节点 |
| **发行机制** | 1份推理算力 = 1份DAICO（分配如下） |
| **总量** | 无上限（根据实际推理需求） |
| **初始供应** | 1亿枚 |

**奖励分配**：
- **80% (0.8份)** → 推理算力提供者
- **20% (0.2份)** → DAICF持有者（按持有比例分配）

## 奖励流程

### 训练任务奖励流程

```
用户提交训练任务
    ↓
节点执行训练任务
    ↓
任务完成验证
    ↓
智能合约发放DAICF
    ↓
节点获得DAICF（1:1）
```

**示例**：
- 节点A完成训练任务，贡献1000算力
- 获得奖励：1000 DAICF

### 推理任务奖励流程

```
用户提交推理请求
    ↓
节点执行推理任务
    ↓
任务完成验证
    ↓
智能合约发放DAICO
    ↓
节点获得80%（0.8份）
DAICF持有者获得20%（0.2份，按持有比例）
```

**示例**：
- 节点B完成推理任务，贡献100算力
- 总奖励：100 DAICO
- 节点B获得：80 DAICO
- DAICF持有者分配：20 DAICO

## 持有者收益计算

假设：
- 总DAICF供应量：10,000,000
- 用户持有：100,000 DAICF
- 当日推理任务总奖励：1,000,000 DAICO

**用户收益**：
```
持有比例 = 100,000 / 10,000,000 = 1%
当日收益 = 1,000,000 × 20% × 1% = 2,000 DAICO
```

## 代币价值支撑

### DAICF 价值来源

1. **训练需求**：构建大模型需要大量训练算力
2. **治理权**：持有DAICF可参与项目治理投票
3. **收益权**：持有DAICF可获得DAICO分红
4. **质押挖矿**：质押DAICF可获得额外收益

### DAICO 价值来源

1. **使用需求**：调用AI服务需要支付DAICO
2. **交易流通**：可在交易所买卖
3. **生态应用**：用于购买AI服务、模型市场等

## 经济模型优势

| 优势 | 说明 |
|------|------|
| **公平激励** | 按贡献分配，多劳多得 |
| **长期持有** | DAICF持有者享受持续分红 |
| **双轮驱动** | 训练和推理互相促进 |
| **防通胀** | 代币价值由实际算力需求支撑 |
| **生态闭环** | DAICO用于购买服务，形成闭环 |
