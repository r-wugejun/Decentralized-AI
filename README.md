# Decentralized AI

利用个人闲置算力构建去中心化AI网络，基于区块链技术发放DAIC代币激励算力提供者。

## 项目愿景

Decentralized AI 旨在创建一个去中心化的人工智能计算网络，让个人用户可以将自己的闲置算力（CPU/GPU）贡献给网络，用于训练和使用AI模型。作为回报，算力提供者将获得 DAIC 代币奖励。

## 核心特性

- 🌐 **去中心化算力网络** - 集合全球闲置算力
- 🤖 **联邦学习** - 保护数据隐私的分布式AI训练
- 💰 **DAIC 代币激励** - 基于贡献量的公平奖励机制
- 🔒 **安全验证** - 零知识证明验证计算结果
- ⚡ **低门槛参与** - 个人电脑即可加入

## 快速开始

### 环境要求

- Python 3.8+
- Node.js 16+
- Git

### 安装

```bash
# 克隆仓库
git clone https://github.com/r-wugejun/Decentralized-AI.git
cd Decentralized-AI

# 安装依赖
pip install -r requirements.txt
npm install
```

### 运行节点

```bash
# 启动算力提供者节点
python src/network/node.py --role provider

# 启动任务请求者节点
python src/network/node.py --role requester
```
